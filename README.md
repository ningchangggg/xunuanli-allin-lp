# 買三送一大禮包落地頁 v3（2026-11-25）：文青可愛風「生活小夥伴繪日記」

阿寧看完電影版 v2：「再生成一個比較文青可愛風格的」。
電影版 v2 保留不動（預覽網址根目錄），這支是另一款給阿寧比較（預覽網址 /cute/）。

## 概念：四個生活小夥伴，陪你過完一整天
- 沿用 v2 片頭那句「這四幕，是你一整天的分鏡」，角色改成可愛的小夥伴名字：
  - 實體日曆＝早安小播報員：每天早上，替你播報今天的那一句話
  - 手機日曆＝隨身小跟班：走到哪跟到哪，解鎖手機就見面
  - 手帳＝生活小祕書：幫你記行程，也聽你說心事
  - 語錄卡＝暖心小信差：把說不出口的話，替你送到對方手上
- 一天四幕：早上 07:30 撕日曆 → 出門 08:40 看手機 → 午後 14:00 咖啡廳寫手帳 → 睡前 22:30 抽語錄卡。
- 每一幕有小夥伴的對話框：「早安！今天這一句，是寫給你的。」「你去哪裡，我就跟到哪裡。」「行程交給我，心事也可以喔。」「說不出口的話，我幫你送過去。」
- 收尾從電影版的「2027，開拍」改成一天結束的「晚安，明天見。」

## 視覺
- 米白點點紙底 #FBF6EC、棕色墨線 #4A3A30。
- 粉彩色塊，每個小夥伴一個顏色：奶油黃 #F6DC8C（日曆／早上）、天空藍 #B9D3E6（手機／出門）、鼠尾草綠 #BFD3B4（手帳／午後）、薰衣草紫 #D5C6E3（語錄卡／睡前），蜜桃粉 #F4C4B4 點綴。
- 手繪小塗鴉都是 SVG：笑臉太陽、雲、紙飛機、咖啡杯、月亮、星星、愛心、虛線路線。
- 商品是白邊貼紙＋紙膠帶＋品名紙條（照組合首圖手帳貼紙版的做法，紙條貼在商品邊緣）。手機只有上半截，切口用「隨身小跟班」紙條蓋住；介紹卡裡的手機從色塊底部的縫線探出來。
- 照片和動圖是白邊相片＋兩角紙膠帶。
- 聖誕節前到貨：紅色禮物牌＋金色縫線框＋金色蝴蝶結，五顆星星輪流閃（2.5 秒一輪）。
- 字：中文全部凝書體（不加粗、不描邊，fontTools 檢查沒有缺字），沒有英文小標，沒有破折號。
