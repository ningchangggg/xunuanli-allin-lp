# 買三送一大禮包落地頁 v1（2026-11-25）：生活電影演員表

阿寧：「還要買三送一大禮包，另外設計一個落地頁。他等於煦暖曆所有商品都買了，這要是完全不同的設計風格，要給他『買這四個產品』可以在他生活扮演什麼角色。」

大禮包＝「我全都要！42折，買三送一」：實體日曆（五選一）＋手帳＋語錄卡＋手機日曆（十六選一）。

## 概念：一部叫《好好生活》的電影
- 你是主角，四個產品是配角，各自「飾」一個生活角色：
  - 實體日曆 飾 每天的開場白
  - 手機日曆 飾 口袋裡的老朋友
  - 手帳 飾 祕書兼樹洞
  - 語錄卡 飾 替你說出口的人
- 一天四場戲：07:30 書桌撕日曆 → 08:40 出門看手機 → 14:00 咖啡廳寫手帳 → 22:30 睡前抽語錄卡。
- 片尾彩蛋：一份大禮包也能拆成四份禮物（日曆送同事、手機兌換碼送遠方朋友、語錄卡送好朋友、手帳留給自己）。
- 收尾：「你負責好好生活，提醒、記錄、打氣，交給它們。」＋場記板「2027，開拍」。

## 跟單品落地頁不一樣的地方
- 單品頁是米白紙感，各自用一個物件當隱喻（登機牌、漫畫格、標本卡、圓角卡片、iOS 介面）。大禮包改成暖黑片場底，視覺語言是電影：膠卷齒孔框、場記板、演員表、通告單、戲院跑馬燈。
- 色票：暖黑 #17120E、深棕 #211A15、奶油字 #F3E9D9、灰褐小字 #B3A48E、琥珀 #E0A65C（強調）、通告單紙 #F2E8D7、磚紅 #BC443C（通告單時間、印章）。
- 結構不照單品頁的「受眾卡 → HOW TO USE」，改成「片頭 → 演員表 → 通告單 → 四場戲 → 選角 → 片尾彩蛋 → 收尾」。範圍照規範：不放首屏、價格、方案、FAQ。
- 字：中文全部凝書體（不加粗、不描邊，fontTools 檢查沒有缺字），英文小標 Helvetica 寬字距。沒有破折號。
